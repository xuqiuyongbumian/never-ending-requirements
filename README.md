# 需求永不眠：1024 极限上线

一款浏览器单机策略游戏。玩家组建研发团队，在 5 分钟交付窗口中自动处理需求、应对变更、控制技术债，并完成最终 GO-LIVE。

## 本地运行

需要 Node.js 22.12 或更新版本。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址即可试玩。开发服务器默认使用 `http://127.0.0.1:5173/`。

## 验证与生产构建

```sh
npm test
npm run build
npm run preview
```

`npm run build` 会先运行 TypeScript 检查，再生成可部署的静态文件到 `dist/`。构建使用相对资源路径，可发布到站点根目录或子目录；游戏本身不需要后端才能游玩。

## 玩法与操作

- 点击工程师卡片或按 `1`–`5` 招募；工程师会自动接单并处理需求。
- 点击时代升级或按 `E`，从手搓时代进化到工程化时代和 Agent 时代。
- 需求变更会暂停模拟；选择会实际改变预算、经验、项目健康、处理速度或技术债。
- 技术债会降低效率，过高时可能触发线上故障。
- 按 `Space` 暂停，点击速度按钮切换 `1×`/`2×`。完成最终 GO-LIVE 即获胜；项目健康归零或 05:00 截止则失败。
- 右上角 `♪` 打开音量设置（总音量/配乐/音效/界面），按 `M` 快速静音。

## 行为数据与数据后台

游戏记录进入、开局、招聘、时代升级、事件选择、优先调度、极限冲刺、需求验收/超时、技术债变化、线上故障、胜负、重玩、中途离开以及暂停/倍速/静音等界面操作。默认仅将最近 1000 条匿名事件保存在当前浏览器的 `localStorage`，并派发 `game:analytics` 自定义事件；结算页展示本局验收需求、招募工程师和事件应对数量，以及本局得分与解锁成就，并可导出本局 JSON。

本仓库提供独立 Node.js + Hono + SQLite API，可批量接收行为事件、保存结算结果，并额外提供：

- **决策分析台**：`/admin`，查看单个匿名会话的完整决策轨迹、对局明细、成就墙，以及全量玩家的需求变更选择、招聘偏好、冲刺/调度节奏、技术债原因和需求结果。
- **排行榜**：`/api/leaderboard`，按最佳得分、胜场或验收需求聚合匿名会话；游戏内结算页和首页可直接打开排行榜。
- **成就系统**：20 项成就由结算 run 与行为事件确定性推导，覆盖交付、团队、决策、风险与速度；游戏内在线上报后由服务端判定，离线时回退到本机事件记录。

本地联调：

```sh
npm run db:migrate
npm run seed:demo        # 可选：写入 12 个演示会话，便于查看后台
npm run dev:server       # API + 后台：http://127.0.0.1:8787/admin
```

在另一个终端创建 `.env.local`：

```dotenv
VITE_API_BASE_URL=http://127.0.0.1:8787
VITE_GAME_VERSION=0.1.0
```

然后运行 `npm run dev`。生产构建未配置 `VITE_API_BASE_URL` 时会默认上报同源 `/api/*`（开发机网关会反代到 API）；本地开发仍保持静默，避免污染数据。生产部署可设置 `ADMIN_TOKEN` 保护后台与 `/api/admin/*`；不设置时后台只建议在本地或内网开放。客户端确认 HTTP 成功后才清除待上传队列；失败会有限重试，事件记录仍留在浏览器。旧版 `VITE_ANALYTICS_ENDPOINT` 仍然可用，但只在未配置新 API 时按单条事件上报。不要把 `ADMIN_TOKEN` 或任何密钥放进 `VITE_` 变量，它们会被打进浏览器构建。

完整 API、成就判定、迁移和限制见 [server/README.md](server/README.md)。

## 美术素材

角色、需求、时代背景和 HUD 图标以独立资源文件由 Phaser 和 DOM HUD 加载，运行时素材位于 `public/assets/game/`。来源、裁切关系和授权说明见 [ASSETS.md](ASSETS.md)。素材包未附独立授权文件，提交比赛前请确认素材的使用授权。

## 声音

配乐与音效全部由 `Web Audio API` 在运行时合成，工程内没有任何音频文件，构建产物不会因此增加体积，也不涉及第三方音频授权。三个技术时代对应三套编制，切换时等功率交叉淡变且不中断；变更弹窗、结算和暂停会自动压低配乐。总线结构、cue 表与验收清单见 [AUDIO.md](AUDIO.md)。
