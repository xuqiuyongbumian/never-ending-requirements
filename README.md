# 需求永不眠：1024 极限上线

一款浏览器单机策略游戏。玩家组建研发团队，在 5 分钟交付窗口中自动处理需求、应对变更、控制技术债，并完成最终 GO-LIVE。

## 本地运行

需要 Node.js 22.12 或更新版本。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址即可试玩。开发服务器默认使用 `http://127.0.0.1:5173/`。

## 验证与生产构建

```sh
npm test
npm run build
npm run preview
```

`npm run build` 会先运行 TypeScript 检查，再生成可部署的静态文件到 `dist/`。构建使用相对资源路径，可发布到站点根目录或子目录；游戏本身不需要后端才能游玩。

## 玩法与操作

- 点击工程师卡片或按 `1`–`5` 招募；工程师会自动接单并处理需求。
- 点击时代升级或按 `E`，从手搓时代进化到工程化时代和 Agent 时代。
- 需求变更会暂停模拟；选择会实际改变预算、经验、项目健康、处理速度或技术债。
- 技术债会降低效率，过高时可能触发线上故障。
- 按 `Space` 暂停，点击速度按钮切换 `1×`/`2×`。完成最终 GO-LIVE 即获胜；项目健康归零或 05:00 截止则失败。

## 行为数据

游戏记录进入、开局、招聘、时代升级、事件选择、需求验收/超时、技术债变化、线上故障、胜负和重玩。默认仅将最近 1000 条匿名事件保存在当前浏览器的 `localStorage`，并派发 `game:analytics` 自定义事件；结算页展示本局验收需求、招募工程师和事件应对数量，并可导出本局 JSON。

跨玩家的远程收集需要提供一个接收 JSON POST 的端点。在 `.env.local` 中设置 `VITE_ANALYTICS_ENDPOINT=https://你的收集服务/events`，然后重新构建。配置后每条事件会通过 `navigator.sendBeacon` 发送，并在不可用时尝试 `fetch` keepalive。当前仓库未配置收集端点，因此本地试玩的数据不会自动上传到服务端。端点需允许来自游戏域名的跨域请求；不要把密钥放进 `VITE_` 变量。
