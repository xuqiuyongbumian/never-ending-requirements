# 需求永不眠：1024 极限上线

一款参加 1024 AI 游戏创作赛的浏览器单机策略游戏。玩家管理研发团队，在 5 分钟的交付窗口内处理需求、权衡技术债并完成最终上线。

## 技术栈

- Phaser 4：程序化像素场景、工程师与需求卡片渲染
- TypeScript：固定步长游戏模拟、任务调度、事件与数值规则
- HTML/CSS：主菜单、HUD、时代升级、需求变更选择和结算
- Vite：本地开发与静态生产构建

## 本地运行

```sh
npm install
npm run dev
```

生产构建：

```sh
npm run build
```

核心规则测试：

```sh
npm test
```

## 核心循环

- 招聘实习生、前端、后端、测试工程师和 AI Agent。角色解锁于不同技术时代，费用、速度、处理效率与专长各异。
- 需求从战场右侧进入，工程师自动移动并协作处理；需求超时会损害项目健康。验收后获得预算和技术经验。
- 技术经验用于升级「手搓时代 → 工程化时代 → Agent 时代」。升级提高团队效率并解锁后端/测试或 AI Agent。
- 快速交付与 Agent 处理会增加技术债。技术债升高会降低效率，超过阈值可能触发线上故障。
- 需求变更会暂停关卡并要求玩家选择，选择会即时影响真实游戏数值。
- 最终 GO-LIVE 需求在 04:00 出现；玩家需要在 05:00 截止或项目健康归零之前完成它。

## 操作

- 点击角色卡片或按 `1`–`5` 招聘
- 点击时代升级或按 `E` 升级
- 按 `Space` 暂停，点击速度按钮切换 `1×`/`2×`
- 需求变更弹窗会暂停模拟，选择后继续

## 行为数据

游戏记录进入、开局、招聘、时代升级、事件选择、技术债变化、需求验收、胜负和重玩事件。默认会保存最近 1000 条到浏览器 `localStorage`，并在页面派发 `game:analytics` 自定义事件；结算页可以导出本局 JSON。

配置 `VITE_ANALYTICS_ENDPOINT` 后，每条事件还会通过 `navigator.sendBeacon`（必要时使用 `fetch` keepalive）发送到该 HTTP 收集端点。事件仅包含匿名会话/对局 ID、时间、游戏内操作和数值，不采集个人身份数据。端点需接受 JSON POST。

## 美术与素材
