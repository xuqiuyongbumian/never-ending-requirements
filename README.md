# Epoch Rush Web

独立的浏览器版游戏项目，参考 `Evolutionary-history-of-war` 中的玩法与内容。原仓库保持不变。

## 技术栈

- Phaser 4：战场画面、场景和输入
- TypeScript：玩法逻辑
- Vite：本地开发与静态构建
- HTML/CSS：网页外壳与后续菜单界面

## 本地启动

```sh
npm install
npm run dev
```

运行 `npm run build` 可生成静态网页文件到 `dist/`。

当前包含一场完整的 A1 人机攻防：四种单位有不同的攻距、伤害和速度；双方会按经济与阵容自动生产，交战击杀会奖励金币与经验。单位受训练队列、24 人口和同阵营间距约束；基地受损会切换状态图。玩家可以暂停、切换速度、重开，并在胜负后看到结算。

经验目前只从实际击杀获得并显示，尚不能用于时代进化；时代与科技、多关卡战役、英雄、存档和难度选择仍未实现。

兵种基础属性参考原仓库 `godot/assets/data/units.json`；A1 战场、兵种动画、基地、图标与特效选用原仓库对应素材。素材来源及许可边界见 [ASSETS.md](ASSETS.md)。

## 操作

- 点击兵种卡片，或按 `1`–`4` 训练单位
- 按 `Space` 暂停或继续
- 点击速度按钮切换 `1×` / `2×`

运行 `npm test` 可检查核心战斗规则和完整胜负流程。测试使用 Node 原生测试运行器与 TypeScript 类型擦除，无需额外测试依赖。
