# 素材源文件

`game_assets_pack.zip` 是初版素材原包，`needs_no_sleep_asset_bundle_v3.zip` 是本轮视觉升级原包，均由用户提供并保存在此目录留档。

按 v3 角色方向修订的透明角色 PNG 位于 `generated-character-art/`。v3 的角色动作表仅作为待重制参考保留在原始压缩包中；当前运行时使用风格统一、轮廓更易区分的高分辨率角色立绘，并由 Phaser 按真实 Idle / Run / Work 状态驱动轻量 Tween。需求与背景 WebP 位于 `public/assets/game/`。资源映射与来源和未采用素材说明见仓库根目录 `ASSETS.md`。
