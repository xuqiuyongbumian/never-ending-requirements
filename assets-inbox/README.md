# 素材源文件

初版与新版完整素材压缩包均已从 Git 历史移除，以减少克隆体积。处理后的运行资源位于 `public/assets/game/`；动作表重建所需的源文件单独保留在 `generated-character-art/animation-sheets/source/`。

按 v3 角色方向修订的透明角色 PNG 位于 `generated-character-art/`。运行时动作表位于 `public/assets/game/animations/`，由 `scripts/prepare-engineer-sprite-sheets.py` 从保留的源文件生成。需求、背景、图标和角色立绘位于 `public/assets/game/`。资源映射、来源和未采用素材说明见仓库根目录 `ASSETS.md`。
